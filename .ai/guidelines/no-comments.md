# Code Comments

- Never write code comments of any kind: no inline comments, block comments, DocBlocks or TODOs.
- This applies to PHP, Vue, TypeScript, JavaScript, CSS, Blade, migrations, config and tests.
- Express intent through clear names for classes, methods and variables, and through small focused methods.
- Use native PHP type hints and return types instead of PHPDoc annotations.
- When editing a file that already has comments, remove them.
